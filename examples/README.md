# 自建样例与诊断

eval_fidelity.py --samples 创建 DOCX/XLSX 合成样例，覆盖标题、文字、字号和两列表格，不含真实用户资料。tests/fixtures/paged-format-reopen.docx 的自建来源和摘要见其 README。

其他 examples 是阶段诊断，运行前阅读参数、资源和授权边界；不对个人文档直接执行批量脚本。真实模型和 Office 开关不属于默认验收。

main.py 仍被桌面回退模型和图片理解代码引用，因此随源码候选保留。R5 独立全量发现上一轮排除它会使图片理解配置失败，现已补回；命令行无显式问题时只显示入口说明，不再自动发送样例，输出不再包含密钥前缀或服务商原始错误。模拟测试不读取真实配置、不请求服务。该兼容模块仍采用 load_dotenv(..., override=True)，本轮未改变既有入口的配置优先级；桌面产品入口为 Start-OfficeAgent.cmd。

旧 MCP 登录、npx/latest 和外部账户说明不再属于产品快速开始，不默认安装、登录或注册工具。产品入口仍为 Start-OfficeAgent.cmd；此前课程材料的 Git 历史和归属没有因本轮排除而宣称审查完成。

公开候选只含清单中的合成回归材料和必要历史静态页面，不复制整个 deliverables、截图、运行日志、用户草稿和模型缓存。开发集不是独立人工评测。
