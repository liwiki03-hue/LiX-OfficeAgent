# 工作区技能

在设置的“技能”中切换“发现 / 已安装”。公开搜索只发送查询词；浏览不要求文档，安装和管理需打开文档并准入其工作区。不会扫描或改动其他 Agent 的技能目录。

“发现”先显示六项固定来源精选，离线可浏览。名称、中文简介、原作者/仓库、提交和许可分开展示；这是来源快照，不是兼容或质量认证。输入先过滤已有结果，Enter或“搜索公开技能”才查询所选来源；切换来源保留输入、不自动联网。“精选目录”可返回快照。当前精选来自Anthropic与Matt Pocock，旧grill-me明确标为固定历史版本，不自动追新。

搜索来源可选skills.sh或OpenAI插件目录。后者读取openai/plugins的marketplace清单，按插件名称/类别匹配，固定提交后最多检查两个插件、显示24项声明的Skill；它不是GitHub全文搜索。只递归所选插件子树，仍保持5000节点、35秒总读取与8秒单请求上限。外部仓库/子目录插件来源暂不跟随，显示未支持；超量时提示缩小查询。插件的安装/认证策略只是来源声明，不能授权LiX安装连接器、MCP、hooks或登录。依赖未接入时阻断安装。

## LiX 技术报告润色

在“发现”的搜索来源中选择“LiX 工作流”，点击“浏览工作流”，可输入“技术报告”筛选。该列表从应用实际携带的SKILL.md读取，不联网；它与公开目录是不同来源。先检查来源与兼容性，再预览安装到当前工作区并独立确认。没有文档时可以浏览，不能安装到浏览器指定的任意目录。

“技术报告润色”1.0.0为本项目原创，AGPL-3.0-only；来源文件是office_agent/assets/skills/report-polish/SKILL.md。v5专门保存应用内版本、来源摘要、原始指令和完整项目许可，不虚构Git提交。仅此本地来源的许可文本可至45000字符，外部v1–v4的20000字符限制不变；完整封装仍≤64KiB，当前包约42KiB。旧格式继续读取，编辑保留来源并标记本地修改，可独立确认撤销。内置工作流随应用更新，不走GitHub更新检查。

使用路径：打开DOCX并同意读取 → 选择正文后“引用选区” → 输入“技术报告润色：精简当前段落，保留数字、单位、引文和未验证条件” → 查看建议 → 采用到草稿 → 保存副本 → 审阅实际变化并独立确认 → 查看结果。安装、采用和写入是三个动作。该技能不扩大文档结构支持，不提供事实核验或新增数值修改权限。

分页编辑器收到真实宿主读取回执后，可显示“已读取参考”。回执绑定当前文档、来源版本、草稿、要求和会话，重复读取合并展示；它可能来自预算准备，不等于模型已经收到、遵从或完成任务。读取详情保留此限制，实际使用还需核对请求和产物。停用后下一轮不加载；工作流不覆盖工具与文件安全规则。

## 安装与使用

搜索公开技能，或填入含40位提交摘要的 GitHub 目录 / SKILL.md 链接。先检查来源、固定版本、许可、原文与参考资料；可兼容时预览安装，再独立确认。安装后重新读取已安装目录；启用只表示可供 Agent 按需选择，不代表模型已经使用或遵从。

技能包保存在工作区 `skills/<内部标识>/SKILL.md`。LiX v1封装保留原始指令、来源和许可；v2额外保存有摘要的静态 Markdown/TXT；v3在相同完整封装上记录用户选定的按需参考模式；v4额外保存受支持的展示sidecar与其明确引用的栅格图标，并保留原有文字加载模式；v5仅用于上述LiX本地工作流来源。仍是一个文件的事务，不是原目录的逐文件复制。旧本地技能、v1/v2/v3/v4继续读取，编辑保留来源、许可、参考资料、展示资源和原有加载模式。

Agent 选中技能时才读取其正文及支持的包内文字。不会注册文件读取、命令或网络工具，不会执行正文、HTML、脚本、MCP或认证流程。最多两项技能、8192字符的原有总加载预算保持，超限不截断正文。

## 当前资料边界

- 远端包最多32个文件、2MiB；单份参考最多16KiB，只支持有界UTF-8 Markdown/TXT。完整封装仍不超过64KiB。
- 完整加载模式的指令和所有参考加标题最多7800字符，并另核对来源信息及技能标识加入后能放进8192字符。只有合计过大、其他检查通过的参考包才提供“改用按需参考模式”；不会自动改用。
- 按需模式保存全部支持的资料，按本次要求与文件名/首行匹配，选择能完整放入预算的文件及其引用依赖。根指令不截断，发送目录和未读提示，并记录所读文件摘要。它是确定性文字匹配，不是语义检索或任意文件工具；无匹配或单文件放不下时不发送该资料，用户可明确名称继续。未读资料不能冒称已核对。
- 支持明确的相对Markdown行内链接，引用最多三层。缺失、循环、越界、保留名、大小写碰撞、图片、引用式链接、可执行文件或未知依赖会阻断；普通网页链接只是文字，不主动访问。
- 支持受限的多行说明与单层字符串metadata映射；原始描述最多1024字符，存储摘要500、模型摘要300，原字节及完整描述保留。未知字段、深层对象、别名/标签、工具和环境声明仍不转成权限。
- 许可证只开放已识别、无冲突的MIT / Apache-2.0受限路径。v4只保存agents/openai.yaml的受限interface字段，以及icon_small/icon_large明确引用的最多两份PNG/JPEG/WebP；其余素材不静默丢弃。每份图标最多512KiB、1024×1024、单帧，扩展名与实际格式必须匹配；完整单文件64KiB上限仍生效，因此不少较大图片包仍会被拒绝。
- 图标与sidecar保留固定原字节/摘要，重开重新校验，传给页面的是重新编码的96px PNG。已安装详情可以查看展示信息、图标和文件清单；完整原始名仍在编辑字段及来源中。展示元数据与图片不进入模型上下文，default_prompt只是展示声明，不自动变成任务。更新比较包含图标/sidecar差异，独立确认与撤销仍覆盖完整封装。
- 不直用外部SVG或远程URL；缺失、损坏、改扩展名、未知sidecar字段、未声明素材和工具依赖会阻断完整安装，图标展示失败退回已有本地图标。其他许可、复杂YAML与完整插件运行时仍不支持。

## 检查更新

已安装公开技能的详情提供“检查更新”。宿主按已保存的仓库和路径检查当前默认分支，固定目标提交后显示原版本、目标版本、文件变化及阻断原因。来源移动不会按同名自动换路径；网络失败、限流或不支持的新元数据均保留当前版本。

“预览更新”后仍需独立确认。检查结果和计划绑定工作区会话、当前文件摘要及目标内容；确认不再联网拉取main。待处理期间换工作区、文件被改或检查过期，必须重查。本地正文或元数据改动会阻断更新，不自动合并。取消无写入，成功后复读目录，可独立确认撤销以恢复原版本及参考资料。

更新不改变启用状态或额外权限。删除仅移除获批的SKILL.md，保留目录中其他用户文件；读取历史不恢复批准。
