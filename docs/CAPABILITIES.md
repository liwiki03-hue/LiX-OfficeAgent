# 能力与证据边界

当前主分支的开发源码版本为 0.7.12。所有文件仍经过准入、源版本核验、独立确认和副本发布，不扩大扫描、工具或云端权限。

| 范围 | 已接入 | 不承诺 |
| --- | --- | --- |
| 打开 | 原生球拖入、文件准入、读取同意、文档内展示 | 未支持格式自动转换写回 |
| DOCX | 普通文本、部分格式/段落/表格行、AI 草稿、locator 失效检查 | 任意域和节、表格列/合并/拆分、全结构原生修订 |
| XLSX | 冻结身份、双向窗口、受限同表计算、依赖缓存 | 全表无缝虚拟化、完整跨表/外链/动态数组、Excel 重算等价 |
| PPTX | 页图、普通文字片段、版本绑定刷新、副本 | 任意绘图/母版/复杂对象编辑 |
| 协作 | 追加要求、停止后阻断后续步骤、过期提案拒绝 | 远端一定取消或不计费、自动冲突合并 |
| 历史 | 结果查看与重新准入 | 恢复读取/写入/外发/撤销批准 |

XML 可解析、库可重开、浏览器交互、渲染与原生操作是不同层次证据。当前冻结候选的真实 Office、物理 IME/DPI/多屏、真实模型、独立人工和完整回归仍有缺项，定向测试不能证明专业质量全部通过。
