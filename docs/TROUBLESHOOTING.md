# 故障处理

| 现象 | 下一步 |
| --- | --- |
| uv 缓存权限拒绝 | 记录阶段/退出码，检查本机账户；不修改缓存 ACL、迁移共享缓存或结束其他进程 |
| 无窗口/CLR 加载失败 | 用标准入口核对 WebView2/.NET/pythonnet 3.0.5，空窗口探针不是业务验收 |
| 下载失败/摘要不符 | 停止安装，核对官方地址和固定摘要，不关闭校验 |
| 文件已变化/旧计划 | 重新准入并生成新计划，旧批准不沿用 |
| 模型 401/限流/超时 | 修复所选接口后主动重试，不自动换付费通道；结果未知先核对产物 |
| 副本未生成 | 检查失败阶段，保留源文件/草稿，未通过闸门不记成功 |
| PPT 页图未更新 | 核对版本和加载状态，等待或主动重试，旧页图不是新草稿证明 |
| 历史文件缺失/替换 | 重新选择和授权读取，历史不恢复路径权限 |
| 深层自定义数据目录提示历史保存失败 | 本机已复现 269 字符的会话临时文件路径创建失败，短路径保存正常；当前不承诺任意长路径。保留当前文字，使用正常本机数据目录；不要为此修改系统策略或绕过路径检查 |

只提供版本、阶段、操作步骤、脱敏错误和自建最小样例。不要上传 .env、密钥、账户库、个人文档或完整日志。计费只有服务商记录可以证明。

开发回归应为每次测试创建较短、独立且明确属于本轮的临时目录。测试数据目录与 uv 共享缓存是不同对象；缩短测试临时目录不意味着迁移 uv 缓存，也不表示长路径产品限制已修复。
