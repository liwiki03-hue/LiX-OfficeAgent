# 参考文献核对

从用户提供的 DOI、明确题名或引用的题录开始，保留实际服务返回的记录标识、作者顺序、题名、年份和 DOI 链接。对照用户提供的题录逐字段指出差异；同名异著分开列出。无法确定的字段标为缺失。只有元数据时，不据此声称论文证明了某项结论。

LiX 使用本轮单次授权向 Crossref 查询书目，并据实际返回记录整理答案。这个技能不编辑正文、引用编号或参考文献表。

本规则由 LiX 改编，参考 K-Dense 的 Citation Management（MIT，ec59a29a03d5c40f73ab40878df04860bc00e876）。选取题录核对和去重流程；未打包上游脚本和网络客户端。
